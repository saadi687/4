GitHub Pages deployment instructions

1. Extract this ZIP on your computer.
2. Open the extracted folder. You MUST see index.html and an assets folder at the same level.
3. Upload BOTH index.html AND the entire assets folder to the ROOT of your GitHub repository.
4. Do NOT upload only the ZIP file. GitHub Pages does not automatically extract ZIP files.
5. In GitHub: Settings → Pages → Deploy from a branch → main → / (root) → Save.
6. Wait a few minutes and open your GitHub Pages URL.

The assets folder contains all JPG images and both H.264/AAC MP4 Reels. The HTML uses relative ./assets/ paths so the media works on GitHub Pages.
